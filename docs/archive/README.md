# Archive

Ce répertoire est une **trace**, pas un état. Rien de ce qu'il contient ne décrit le
protocole courant, et plusieurs documents affirment le contraire de ce que fait le
code aujourd'hui.

Il est conservé pour une seule raison : une décision se juge mieux quand on voit ce
qu'elle a remplacé. Supprimer ces fichiers rendrait le dépôt plus propre et le
raisonnement moins vérifiable.

| répertoire | contenu |
|---|---|
| `audits/` | audits antérieurs à celui du 13/08/2026, dont l'audit interne adversarial du 25/07/2026 (4 critiques, 8 hauts, corrigés derrière le fork v7) et une archive HTML de l'époque où le projet s'appelait Torus |
| `journals/` | journal d'itérations d'une campagne de durcissement, arrêté au 13/07/2026 |
| `design-notes/` | notes de conception supersédées : une tokenomique v2 jamais adoptée, une proposition de sécurité par réputation **explicitement rejetée par l'ADR-002**, une feuille de route Web3 abandonnée |
| `plans/` | plans de remédiation clos |
| `specs/` | les bons de commande de développement des campagnes précédentes, rédigés à l'impératif pour un exécutant. Beaucoup annoncent encore « à exécuter » un travail livré depuis. Les décisions qu'ils contenaient ont été ratifiées dans [`../decisions/`](../decisions/) et les protocoles décrits dans [`../protocol/`](../protocol/) |

Pour l'état courant, retourner à [`../README.md`](../README.md).
