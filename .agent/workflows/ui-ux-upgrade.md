# UI/UX & Visual Upgrade Workflow

This workflow transforms a basic frontend interface into a premium, modern, and highly polished user experience. 

## When to use
Use this when the user wants to improve the visual aesthetics, responsiveness, or UX of an existing component or page.

## Instructions for Claude

1.  **Analyze the current UI**:
    *   Examine the target HTML/CSS/JS or framework files.
    *   Identify generic colors, default typography, poor spacing, or lack of animations.

2.  **Propose a Design System**:
    *   **Colors**: Suggest a sleek, modern palette (e.g., deep dark mode with vibrant neon accents or a clean glassmorphism light theme).
    *   **Typography**: Use modern fonts (Inter, Roboto, Outfit).
    *   **Spacing**: Ensure consistent, readable padding and margins.

3.  **Implement Visual Excellence**:
    *   Add subtle micro-animations (e.g., hover effects, smooth transitions, loading states).
    *   Use gradients, modern borders, and shadows to create depth.
    *   Ensure the layout is perfectly responsive across desktop and mobile devices.

4.  **Action Plan**:
    *   Present the proposed changes to the user (with a quick mock if possible).
    *   WAIT for the user's confirmation.
    *   Apply the changes systematically, ensuring no core functionality is broken.
